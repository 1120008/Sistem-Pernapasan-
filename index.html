🔐 SaaS Architecture

Aplikasi ini sudah dipisahkan secara konsep menjadi tenant → users → classes → assignments → attempts → progress. Mode GitHub Pages saat ini menggunakan localStorage sebagai demo; data produksi sebaiknya dipindahkan ke database + authentication + payment provider.

⚠️ Jangan menaruh secret key database/payment di frontend GitHub Pages. Gunakan backend/serverless functions untuk transaksi dan webhook.
